# Quản lý công việc Tổ Kỹ thuật điện & IC

Ứng dụng web chạy hoàn toàn trên trình duyệt (một file `index.html`), không cần máy chủ.

- Mở ứng dụng: https://ngocnam-eps.github.io/qlcv-to-dien/
- Bản đưa lên web **không kèm dữ liệu**. Dữ liệu lưu riêng trong trình duyệt của từng máy.
- Để đưa dữ liệu vào: mục **Thành viên & Cài đặt → Khôi phục từ file** (file sao lưu `.json`).
